# mini project sql
## Tujuan project
Tujuan dari assignment ini adalah untuk mengukur pemahaman peserta dalam membuat ERD, membangun skema database MySQL menggunakan DDL, mengelola data dengan DML, serta menjalankan berbagai query SQL mulai dari dasar hingga join dan agregat. Hasil tugas ini dapat digunakan sebagai portofolio untuk menunjukkan kemampuan peserta dalam dasar-dasar database dan SQL.
